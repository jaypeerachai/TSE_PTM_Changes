# 🗄️ Database

This folder contains the Zenodo url for the SQL database schema used in the replication package of:

**When AI Models Become Dependencies: Studying the Evolution of Pre-Trained Model Reuse in Downstream Software Systems**.

The schema covers downstream repositories, software evolution metadata (commits/issues/pull requests/releases), PTM static-analysis evidence, and release-line PTM change outcomes.

For large database files and the archival data release, please use Zenodo:

📦 **DOI:** https://doi.org/10.5281/zenodo.19312247
